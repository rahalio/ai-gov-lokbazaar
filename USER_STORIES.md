# Lokbazaar — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Ministry / PSU problem owner

- As a mission director, I want to publish a sector problem and see linked datasets, annotation capacity, and trialable models, so that my team stops relying on a single SI’s private data network.
- As a procurement officer, I want trial access results attached to the award file, so that purchase decisions are evidence-based.
- As a PSU digital lead, I want price benchmarks for annotation and data licences, so that I can challenge informal quotes.

### Data custodian

- As a hospital data officer, I want to licence an anonymised dataset with an access audit trail, so that I can share for AI without losing control to silent resale.
- As a custodian, I want the system to refuse a listing that lacks lawful basis metadata, so that non-compliant data cannot enter the market under my name.

### Annotation enterprise / worker

- As an annotation lead, I want job-level accuracy standards and sampled QA, so that payment disputes reference a published bar.
- As a programme designer, I want annotation demand visible by skill and language, so that #AIforAll job creation is targetable in regions with surplus labour.

### Model vendor / startup

- As a startup founder, I want to list a model with trial access and sector tags, so that government buyers can find me without an incumbent relationship.
- As a vendor, I want suspension rules published in advance, so that quality enforcement is predictable.

### CORE / ICTAI researcher

- As a CORE researcher, I want to publish a research artefact with ethics-council status, so that downstream ICTAI application teams inherit provenance.
- As an ICTAI lead, I want moonshot project outputs to appear as solution listings tied to inter-ministerial problems, so that research spending shows a path to deployment.

### Marketplace operator / ethics officer

- As an ethics officer, I want FAT review completion before healthcare models become procurement-ready, so that social-sector deployments do not skip accountability.
- As an operator, I want to suspend a seller after repeated QA failures, so that ratings alone cannot mask systemic defect.
